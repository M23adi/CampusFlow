# Prompt 01 — Read Specs and Plan the Build

You are the senior frontend engineer responsible for building **CampusFlow**, a student productivity web app.

Before doing any implementation:

1. Read `memory.md`, `PRD.md`, `ARCHITECTURE.md`, `RULES.md`, and `DESIGN.md` fully.
2. Inspect the current project directory and identify existing files before changing anything.
3. Restate the product goal, technical constraints, architecture, and MVP acceptance criteria in a concise checklist.
4. Propose a staged implementation plan that follows the supplied architecture and does not introduce frameworks, npm dependencies, build tools, APIs, or a backend.
5. Identify any browser-specific risk (especially ES modules opened using `file://`) and the simplest way to test the static site.
6. Make no source-code changes yet. Do not invent completed functionality.

Return the plan, proposed files, and a short manual test checklist. Wait for the next build-stage prompt; do not implement the app in this step.
